## 🟢 Phase 1 — Understanding the Data World

Before building any AI system, we first focused on understanding real receipt data.

We explored the **SROIE2019 Dataset**, which contains receipt images, OCR annotations, and document entity labels. We analyzed folder structures, image files, text annotations, and pretrained document AI models.

This step was important because we believe:

> Before building intelligence, data must be understood properly.

So our first stage was validating whether the dataset was complete, organized, and suitable for machine learning.

---

## 🟢 Phase 2 — Teaching Machines to Read Receipts

Once we understood the data, the next challenge was:

> Can a machine understand what type of expense a receipt represents?

We created receipt text examples such as grocery bills, restaurant bills, shopping receipts, transport fares, and pharmacy invoices.

Then we applied Artificial Intelligence techniques such as:

* TF-IDF for converting text into numerical features
* Naive Bayes for fast text classification
* Support Vector Machine for accurate separation
* Neural Networks for learning deeper patterns

Now the system could classify receipts into categories like:

* Food
* Groceries
* Shopping
* Transport
* Healthcare

At this stage, receipts stopped being paper documents and became understandable digital data.

---

## 🟢 Phase 3 — Turning Data into Human Stories

Then we realized something important.

Expenses are not only numbers.
They belong to people.

So we introduced multiple user profiles such as Aman, Riya, Kunal, and Sneha to simulate real-world users.

Now the project started answering questions like:

* Who spends the most?
* Who saves more?
* Who shops frequently?
* Which category does each person spend on most?
* What is each user’s spending behavior?

This transformed the project from a simple tracker into a human behavior analytics system.

At this point, receipts became stories of people’s lifestyles.

---

## 🟢 Phase 4 — Predicting the Future

Tracking past spending is useful, but intelligent systems should also predict future trends.

So we implemented forecasting models such as:

* Linear Regression
* Ridge Regression
* Random Forest Regressor

Using these models, the system could estimate:

* Next month expenses
* Weekly trends
* Future growth in spending
* Budget risk patterns

This made the project smarter because it moved from history analysis to future planning.

---

## 🟢 Phase 5 — Detecting Unusual Behavior

Then we thought:

> What if someone suddenly spends unusually high amounts?

So we implemented anomaly detection using **Isolation Forest**.

This allowed the system to identify:

* Irregular purchases
* Sudden expense spikes
* Unusual financial behavior
* Potential fraud-like activity

Now the project was not just reactive—it became proactive.

---

## 🟢 Phase 6 — Discovering Financial Personalities

Next, we used clustering algorithms like:

* KMeans
* PCA for visualization

This automatically grouped users into spending personalities such as:

* High Spender
* Conscious Saver
* Frequent Moderate
* Selective Premium

This means the project was no longer just tracking expenses.

It was understanding people.

---

## 🟢 Phase 7 — Building a Real Product

Finally, we transformed all notebook research into a working product.

We built a modern web application using:

* Gradio Interface
* EasyOCR for receipt scanning
* Chat-style assistant UI
* Sidebar analytics dashboard
* CSV export system
* Multi-receipt upload support

Now users can:

* Upload receipts instantly
* Ask chatbot questions about spending
* View summaries and category reports
* Export records anytime

This is where research became a usable real-world solution.
